# Tessera Simulator

Программная среда для исследования и отладки алгоритмов построения остовного дерева на графе ячеек. 

Симулятор реализован с использованием библиотеки `PyQt5` и позволяет задавать произвольные фигуры, состоящие из соединённых квадратных ячеек, а также поэтапно наблюдать работу распределённого алгоритма.

[!Интерфейс программы](images/interface.png)

Каждая ячейка представлена отдельным объектом с одинаковой программной логикой. Благодаря этому все ячейки выполняют алгоритм и обмениваются сообщениями по одинаковым правилам, что соответствует модели распределённой системы с однородными узлами.

Симуляция выполняется по дискретным временным шагам. На каждом шаге каждая ячейка выполняет свою часть алгоритма и может передавать данные одному или нескольким непосредственным соседям.

Каждое сообщение состоит из двух частей:

* `command` — код команды;
* `data` — передаваемое значение.

В рамках одного временного шага передача данных по каждому ребру графа возможна только в одном направлении. Поэтому две соединённые ячейки не могут одновременно передавать друг другу данные. При этом все ячейки выполняют операции передачи и приёма параллельно, что позволяет моделировать синхронную работу распределённой системы.

Порядок инициирования передач выбирается случайным образом. Это позволяет моделировать недетерминированность временных процессов и проверять работу алгоритма при различных порядках обмена сообщениями.

Интерфейс симулятора позволяет наблюдать работу алгоритма на каждом временном шаге. Дополнительную информацию о состоянии отдельной ячейки можно просматривать через панель настроек.
